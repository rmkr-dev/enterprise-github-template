# Support

## This repository

`enterprise-github-template` is a **GitHub repository template** (docs, process, and CI hygiene). It is not a hosted product and does not offer a support SLA.

| Need | Where to go |
| --- | --- |
| How to use or contribute | [README.md](README.md), [docs/development/development.md](docs/development/development.md), [CONTRIBUTING.md](CONTRIBUTING.md) |
| CI/docs not validating | [Troubleshooting](docs/operations/troubleshooting.md) |
| Bug in the template | [Bug report](https://github.com/rmkr-dev/enterprise-github-template/issues/new?template=bug_report.yml) |
| Improvement idea | [Feature request](https://github.com/rmkr-dev/enterprise-github-template/issues/new?template=feature_request.yml) |
| Small starter task | [Good first issue](https://github.com/rmkr-dev/enterprise-github-template/issues/new?template=good_first_issue.yml) or browse the `good first issue` label |
| Security vulnerability | [SECURITY.md](SECURITY.md) — private advisory, not a public issue |
| Template-scoped incident (secret in git, unsafe workflow) | [Incident response](docs/operations/incident-response.md) then [SECURITY.md](SECURITY.md) if disclosure is needed |
| Conduct concern | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Maintainer contact for this template is `@rmkr-dev` on GitHub. Do not publish personal email addresses here.

## Derived repositories

Support for products created **from** this template is owned by those repositories. Point their users at their own README and security policy after you rewrite them.
